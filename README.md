# Twype

Tinder-style prediction markets on Starknet. Swipe right to bet "YES" or left to bet "NO" on prediction markets.

## Features

- Swipe-to-bet interface
- Starknet wallet integration (ArgentX, Braavos)
- Market creation
- Portfolio tracking
- STRK token support

## Usage

1. Connect your Starknet wallet
2. Set your default bet amount in settings
3. Swipe right for "YES" or left for "NO" on prediction markets
4. Review bets in your betslip
5. Create custom markets via "Create Market"
